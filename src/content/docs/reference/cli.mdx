# CLI

Verified against the Typer command tree in `src/blitzecdn/cli.py` at v1.1.0.

## Safety and automation

| Command | Remote side effects | Safe to retry blindly? | Automation note |
| --- | --- | --- | --- |
| `doctor`, `validate`, `status`, `audit` | None | Yes | Prefer `--json` where available. |
| `plan` | Ansible check mode; should not converge | Rerun after any state change | Review the resulting record before deploy. |
| `domain add/remove`, `record add/proxy/remove`, `edge add/remove` | Controller state only | No | Review the resulting desired state. |
| `dns export` | None | Yes | Feed to the system that publishes DNS. |
| `deploy` | Previews, then converges every configured edge | No | Interactive by default; use `--yes` only after separate checks in automation. |
| `rollback` | Converges a snapshot, then changes canonical state | No | Preview with `--check`; select a known successful snapshot. |

Commands that accept `--json` write stable machine-readable output. Diagnostic
logs remain separate; do not parse human output for automation.

## `blitzecdn edge`

Manage edge servers without editing Ansible inventory YAML directly.

```bash
blitzecdn edge add edge-01 --host 192.0.2.10 \
  --user deploy --ssh-source 198.51.100.0/24
blitzecdn edge list
blitzecdn edge remove edge-01
```

### `blitzecdn domain import`

Converts sites created before v1.1.0 into the proxied records that reproduce
them. See [Domains and records](/docs/reference/domains).

| Argument or flag | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `names` | `str...` | `true` | — | Every zone to import. List them all at once. |
| `--force` | `boolean` | `false` | — | Drop hostnames whose zone you did not list. |
| `--json` | `boolean` | `false` | — | Emit machine-readable JSON. |

Reports three lists: `imported`, `skipped` (sites needing a human, such as a
hostname origin), and `dropped` (hostnames that will stop being served).

<Callout type="error">
  Pass every zone in one command. The first import rewrites the derived table
  and destroys the sites a second run would have read. The command refuses and
  writes nothing when a hostname belongs to a zone you did not list.
</Callout>

### `blitzecdn domain remove`

### `blitzecdn record proxy`

Turns the CDN on or off for one record.

| Argument or flag | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `domain` | `str` | `true` | — | Zone the record belongs to. |
| `name` | `str` | `true` | — | Record name. |
| `--on` / `--off` | `boolean` | `true` | — | Route through the CDN, or bypass it. |
| `--type` | `A` \| `AAAA` | `false` | `A` | Record type. |
| `--json` | `boolean` | `false` | — | Emit machine-readable JSON. |

<Callout type="warning">
  The edge changes on the next deploy, but the switch only reaches clients once
  DNS answers accordingly. Change both together: an unproxied hostname whose DNS
  still points at an edge is answered by the catch-all with `444`, not by your
  origin.
</Callout>
