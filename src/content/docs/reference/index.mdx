# Reference

These pages describe exact public interfaces. They are maintained MDX, not
generated, so read them alongside the release you are running.

- [CLI](/docs/reference/cli) — every command, flag, and exit code.
- [Domains and records](/docs/reference/domains) — zones, A records, and the
  per-record CDN proxy toggle.
- [HTTP API](/docs/reference/api) — every route, model, and status code.
- [Configuration](/docs/reference/configuration) — every `BLITZE_*` variable and
  its TOML equivalent.
- [Ansible roles](/docs/reference/roles) — every role variable, typed, with
  defaults.

The control plane and the edge collection release separately and share a
versioned desired-state contract. `EDGE_COLLECTION_VERSION` in the control plane
records the collection it deploys, and the Nginx role refuses a desired-state
version it was not written against — a mismatched pair fails before the first
host is touched.
