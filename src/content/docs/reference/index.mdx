# Reference

These pages describe exact public interfaces. They are maintained MDX, not
generated, so read them alongside the release you are running.

Use [Operate BlitzeCDN](/docs/operate) when you need an ordered workflow. Use
this section when you need the exact meaning of a command, field, setting, or
role variable.

- [CLI](/docs/reference/cli) — every command, flag, and exit code.
- [Domains and records](/docs/reference/records) — zones, A records, and the
  per-record CDN proxy toggle.
- [HTTP API](/docs/reference/http-api) — every route, model, and status code.
- [Configuration](/docs/reference/configuration) — every `BLITZE_*` variable and
  its TOML equivalent.
- [Ansible roles](/docs/reference/ansible) — every role variable, typed, with
  defaults.

The roles ship with the control plane in `ansible/roles/`, so one release
covers both and they cannot drift. The versioned desired-state contract still
applies to edges: the Nginx role refuses a desired-state version it was not
written against, so an edge last converged by an older release fails before it
is touched rather than serving a configuration nobody reviewed.
