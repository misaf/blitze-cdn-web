# BlitzeCDN documentation

Use BlitzeCDN to manage Nginx CDN edge servers from one controller. Choose the
path that matches what you need now.

The product has a strict responsibility split:

- **Python** owns validation, desired state, deployment history, planning,
  rollback, audit records, and process execution.
- **Ansible** exclusively owns remote Linux state. It carries defensive
  validation but no product workflow decisions.

The project is opinionated: Debian 12+ and Ubuntu 24.04+ edges, OpenSSH
host-key verification, non-root SSH users with explicit sudo, UFW, Fail2Ban,
centrally coordinated ACME HTTP-01 issuance, managed certificate uploads, and
existing TLS certificate paths. Certificates are issued once by the controller
and distributed to every edge.
